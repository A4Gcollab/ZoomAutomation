# Product Requirements Document (PRD)

## 1. Overview
**Product Name:** YTZ (YouTube-to-Zoom) Automation System  
**Version:** 1.0  
**Date:** January 11, 2026  
**Status:** In Production

### Purpose
Automate the complete workflow of Zoom cloud recording management by downloading recordings, uploading to YouTube for compression, and backing up to Google Drive with organized folder structures.

## 2. Problem Statement
Organizations using Zoom generate large volumes of cloud recordings that need to be:
- Downloaded before Zoom's automatic deletion (typically 30-90 days)
- Compressed to save storage costs
- Backed up to long-term storage (Google Drive)
- Organized in a searchable folder hierarchy

## 3. Goals & Objectives
- **Business Goals:** Eliminate manual recording management, reduce costs, prevent data loss.
- **User Goals:** Set-and-forget automation, organized archive, reliable backup.

### Technology Stack

# Deployment Guide (Google Cloud)

## Step 1: Create VM
- **Machine Type:** `e2-standard-2` (Recommended)
- **OS:** Ubuntu 22.04 LTS
- **Disk:** 30 GB Standard

## Step 2: Install Docker
```bash
sudo apt-get update && sudo apt-get install -y docker.io docker-compose
sudo usermod -aG docker $USER
```
*(Relogin required)*

## Step 3: Deployment
1.  Upload files (src, config, secrets, Dockerfile, docker-compose.yml).
2.  Run:
    ```bash
    docker-compose up -d --build
    ```
